# 2D_Game
#细胞战舰（Cell Battleship）
###一款以微观细胞世界为背景的游戏，使用 Unity 和 C# 开发。
##项目介绍
###《细胞战舰》是一款正在开发中的游戏项目，围绕细胞主题构建游戏场景、角色系统与交互界面。
##开发环境
游戏引擎：Unity 2022.3.62f3
开发语言：C#
目标平台：Windows PC
版本管理：Git / GitHub

##项目状态
初步开发完成，后续还需要继续优化

##核心玩法
玩家操控细胞收集营养球，通过分裂来提升自己的属性，与其他敌人细胞争抢营养球和战斗，通过分数的形式展现结果。
