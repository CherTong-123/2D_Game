# 细胞战舰（Cell Battleship）

## 🎮 项目简介

《细胞战舰》是一款以细胞为主题的游戏，玩家将在微观生物世界中展开冒险与战斗。

本项目由 Game Jam 团队合作开发，融合了策划、程序与美术设计，旨在打造独特的细胞主题游戏体验。

> **游戏类型：** 策略、生存  
> **开发引擎：** Unity 2022.3.62f3  
> **运行平台：** Windows  
> **项目状态：** 持续开发中
